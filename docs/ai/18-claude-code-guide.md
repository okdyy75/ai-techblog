# Claude Code 実践ガイド：Anthropicの革新的AIコーディングツール

## 1. Claude Codeとは

**Claude Code** は、Anthropic社が提供するCLIベースの自律型AIコーディングアシスタントです。従来のエディタ拡張型AI（CopilotやCursorなど）とは異なり、ターミナル上で直接動作するのが最大の特徴です。

プロジェクト全体のコンテキストを理解した上で、自律的にファイルの読み書き、シェルコマンドの実行、さらにはテストの実行と修正までを一貫して行うことができます。単なる「コード補完」を超えて、より「エージェント的（Agentic）」に振る舞う開発の強力なパートナーとなります。

### 主な特徴
- **ターミナルネイティブ**: 使い慣れたターミナル環境でシームレスに動作し、特定のエディタに依存しません。
- **自律的なタスク実行**: ファイルの検索、コードの修正、Linterやテストの実行までの一連のフローをClaudeが計画・実行します。
- **深いコンテキスト理解**: プロジェクトのコードベース全体を素早く把握し、依存関係やアーキテクチャの文脈を踏まえた正確な修正が可能です。

## 2. インストール方法

Claude Codeはnpmパッケージとして提供されています。Node.js環境（v18以上推奨）がインストールされている必要があります。

```bash
# グローバルにインストールする場合
npm install -g @anthropic-ai/claude-code

# インストールせずに直接実行する場合
npx @anthropic-ai/claude-code
```

### 初期設定（認証）

初めて起動する際は、Anthropicのアカウント認証が必要です。ターミナルで以下のコマンドを実行します。

```bash
claude login
```

ブラウザが開いて認証を求められるので、Anthropic Consoleの認証情報を入力してログインします。（※利用にはClaude APIの料金がかかる点に注意してください）

## 3. 基本的な使い方

プロジェクトのルートディレクトリで `claude` コマンドを実行すると、対話型のプロンプトが起動します。

```bash
cd my-project
claude
```

起動後、以下のように自然言語で指示を出します。

```text
> ユーザー登録のバリデーションロジックを auth.js に追加して
```

すると、Claude Codeは自律的に以下のステップを踏みます：
1. `auth.js` ファイルを検索して内容を読み込む
2. 必要なバリデーションコードを追加・上書き保存
3. 変更内容のサマリーをターミナルに表示する

**ワンショットでの実行**
対話モードに入らず、引数で直接指示を渡すことも可能です。CIやスクリプトから呼び出す際に便利です。
```bash
claude -p "README.mdに現在のディレクトリ構成を追記して"
```

## 4. 実践的な使用例

### ① 新機能のコード生成と組み込み

具体的な仕様を伝えて、ゼロからファイルを生成・構築させることができます。

```text
> 以下の要件でExpressのユーザー情報取得APIを作成してください。
> - エンドポイント: GET /api/users/:id
> - DBはPostgreSQLを使用（pgライブラリ）
> - エラーハンドリングを含めること
> 作成したら、routes/index.js に組み込んでください。
```

### ② 大規模なリファクタリング

複数ファイルにまたがる修正も得意です。自分で該当箇所を検索して一括で変更してくれます。

```text
> src/utils 内にある日付フォーマットの処理が各ファイルに散らばっています。
> これらをすべて src/utils/dateFormatter.js に集約し、
> 呼び出し元のファイルをすべて新しいモジュールを使うように書き換えてください。
```

### ③ テストの作成と自動修正（バグ修正）

Claude Codeの最大の強みは「コマンドを実行して結果をフィードバックできること」です。

```text
> src/services/payment.js の単体テストをJestで作成してください。
> 作成後、ターミナルで `npm run test` を実行し、もしテストが落ちた場合は
> テストが通るようになるまでソースコードまたはテストコードを修正してください。
```
この指示により、Claudeは「テスト作成 → テスト実行 → エラーログ解析 → コード修正 → 再テスト」のループを自律的に回してくれます。

## 5. ベストプラクティスと注意点

### 明確なコンテキストの提供
Claude Codeは優秀ですが、巨大なプロジェクトでは関連ファイルを見つけるのにトークンと時間を消費します。「〇〇ディレクトリの～」「〇〇の機能について」と対象を絞ることで、速度とコスト効率が劇的に向上します。

### `.claudeignore` の活用
デフォルトで `.gitignore` を尊重しますが、Claudeに読み込ませたくない大きな自動生成ファイルや機密ファイルがある場合は、プロジェクトルートに `.claudeignore` を配置して除外ルールを記述します。

### セキュリティと実行権限の確認
Claude Codeはシェルコマンド（ファイル削除、npm install、ビルド実行など）を実行する能力を持っています。重要な変更や破壊的なコマンドを実行する前には確認プロンプト（Y/n）が出ますが、**「何をしようとしているか」の実行計画を常に目視確認**してから許可するようにしてください。

### APIコストの管理
自律的にファイル検索や複数回のやり取りを行うため、APIのトークン消費（特にClaude 3.5 Sonnet等の強力なモデルを使用している場合）が大きくなる傾向があります。Anthropic Consoleで利用上限（Usage Limit）やアラートを適切に設定しておくことを強くお勧めします。

## 6. まとめ

Claude Codeは、単なる「コードを補完するツール」から「自律的にタスクを完遂するAIエンジニア」へと、AI開発体験のパラダイムシフトを体現する強力なCLIツールです。

エディタを問わず、インフラ設定からフロントエンドの実装、テストの自動修復までをターミナル一つで完結できるため、日々の開発ワークフローに組み込むことで圧倒的な生産性の向上が期待できます。まずは小さなタスクや自動テストの修復から、ぜひあなたのプロジェクトでも試してみてください。
